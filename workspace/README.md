# 🏢 Workspace Skills

Este diretório é reservado para **habilidades específicas de projetos ou workspaces**.

Enquanto a pasta `global/` armazena padrões universais e regras reutilizáveis de tecnologia, este diretório é destinado a:
- Regras de arquitetura interna de produtos ou monorepos específicos.
- Instruções de contexto para domínios de negócio restritos.
- Scripts de automação customizados para ambientes corporativos ou clientes.

---

## Estrutura Recomendada

```text
workspace/
├── <projeto-ou-workspace>/
│   └── <skill-name>/
│       └── SKILL.md
└── README.md
```
